# mate

> «У mate нет двух одинаковых причин его пить».

Концептуальная TEA-библиотека (The Elm Architecture) для Kotlin
Multiplatform: чистые reducer'ы, эффекты и подписки как данные,
однонаправленный цикл с гарантиями runtime — и сценарные тесты
бизнес-логики целого приложения.

Статус: **v0 в разработке** (каркас). API нестабилен.

## Принципы

Mate следует TEA буквально — с одним собственным принципом поверх:

- **Model** — единственный иммутабельный источник истины; всё поведение
  выводимо из него.
- **Update** — чистая тотальная функция
  `reduce(state, message) → (state, effects)`.
- **Эффекты — данные.** Reducer описывает намерения значениями;
  исполняет runtime; результат возвращается новым Message в тот же
  цикл. Никаких колбэков в обход.
- **П1 — различимые намерения.** Эффекты одного reduce образуют
  МНОЖЕСТВО: неразличимый дубль намерения не имеет семантики.
  Различимость (включая идемпотентность кумулятивных команд) обязана
  жить в данных эффекта.
- **Гарантии runtime — свойство библиотеки, не дисциплина вызывающего:**
  сообщения обрабатываются строго по одному (mailbox, FIFO), ошибки не
  убивают цикл, невалидная конфигурация громко падает.
- **Подписки декларативны** (roadmap v1): `subscriptions(state)` —
  активные подписки выводимы из Model, «подвисшая подписка» невозможна
  по построению.
- **Навигация — данные** (roadmap v1): таблица переходов одна,
  интерпретаторов двое — прод и тестовый харнес.
- **Сценарные тесты приложения** (roadmap v2): все экраны + живая
  навигация + стабы use case'ов, JVM, полная трасса при падении.

## Артефакты

| Артефакт | Что это | Статус |
|---|---|---|
| `mate-core` | раннер: reducer, эффекты, mailbox, observer | каркас |
| `mate-navigation` | NavigationEffect, navGraph, гейт-очередь | план v1 |
| `mate-test` | тестовые хелперы reducer'ов/раннера | план v0 |
| `mate-app-test` | сценарный харнес приложения | план v2 |

## Подключение (JitPack, период обкатки)

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        maven("https://jitpack.io")
    }
}

// build.gradle.kts
dependencies {
    implementation("com.github.KilgoreT.mate:mate-core:<tag>")
}
```

Таргеты v0: `android`, `jvm`. iOS — с публикацией в Maven Central.
